The NVIDIA API Catalog provides developers with hosted inference endpoints for a broad range of models. The quickstart guide shows how to interact with a model that has been hosted as a NIM through a live API endpoint, both directly through a web-based UI and through Python code. The service hosts these models on NVIDIA DGX Cloud infrastructure, giving developers access to state-of-the-art language models and retrieval systems without provisioning their own GPUs.

Browsing the catalog: the entry point is build.nvidia.com, which shows the full catalog of NIM microservices. Users can browse available models by model type or by industry vertical, or use the search function to locate a specific service. This gives a straightforward discovery mechanism for identifying an appropriate model before committing to integration. The sidebar navigation distinguishes at least two primary NIM categories: Language NIMs for natural language processing tasks and Retriever NIMs for retrieval-augmented generation applications.

Trying a model in the browser: opening a specific model, with Llama-3.1-8B-instruct used as the guide's example, brings up a dedicated model page with an integrated preview. The preview permits direct interaction through a conversational chat window. Users can select one of the provided example prompts or compose a custom query by typing into the text input and pressing send. The underlying API infrastructure processes the request and returns the model-generated response inside the browser, creating an immediate feedback loop for experimentation and evaluation before any code is written.

Account creation and API key generation: developers who want to call the endpoints programmatically must create an account in NVIDIA's developer ecosystem. The flow starts by clicking Get API Key on the model page. The user then enters an email address in a popup window, which simultaneously enrolls them in the NVIDIA Developer Program. Existing NVIDIA account holders are prompted for the credentials associated with that email; new users are guided through password creation. On successful authentication or account creation, a popup window shows the new API key. The documentation instructs developers to paste the key somewhere safe, since it is the authentication credential for all programmatic requests and must be treated as a sensitive secret.

Python integration: the platform streamlines first integration by providing copy-paste-ready Python code samples. Developers click the Copy Code button to copy the Python code shown in the pane on the right and paste it into their development environment. The template includes placeholder values that must be customized. The critical step is replacing the placeholder string API_KEY_REQUIRED_IF_EXECUTING_OUTSIDE_NGC with the actual API key obtained during registration. Developers then replace the sample prompt, which in the documentation example is a request to write a limerick about the wonders of GPU computing, with their own input targeted at their application.

Model scope: the quickstart uses Llama-3.1-8B-instruct as an illustrative example, but the same guide applies to any model available in the NVIDIA API Catalog, which spans different architectures, sizes, and specializations.

Next steps toward production: API Catalog access is positioned as the entry point into a broader ecosystem. Beyond browser interaction and simple Python integration, developers can progress to self-hosting through the NIM Deployment Quickstart Guide and local deployment resources, so teams commonly graduate from API Catalog usage to managing their own containerized NIM instances. References to NVIDIA Brev and the GenerativeAIExamples repository provide integrated pathways for managed deployment and educational resources, and FAQ sections covering general product questions, deployment scenarios, and debugging support developers moving from initial experimentation to production-scale implementations.
