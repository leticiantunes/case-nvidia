NVIDIA Isaac is an open robotics development platform designed to accelerate AI robot development. The platform consists of simulation and robot learning frameworks, NVIDIA CUDA-accelerated libraries, AI models, and reference workflows for creating autonomous mobile robots (AMRs), robot arms, manipulators, and humanoids. The platform provides a full-stack CUDA-acceleration approach with optimized AI models for developing, training, simulating, deploying, operating, and optimizing robot systems.

For manipulation tasks, NVIDIA cuMotion is a CUDA-accelerated library that solves robot motion planning problems by running multiple trajectory optimizations simultaneously. FoundationPose serves as a foundation model for 6D pose estimation and tracking of novel objects, handling challenging properties like textureless surfaces and glossy finishes. FoundationStereo achieves strong zero-shot generalization for stereo matching depth estimation. SyntheticaDETR is a pretrained model for object detection in indoor environments. Isaac TeleOp enables collection of high-quality human demonstrations through teleoperation in the real-world and simulation.

For mobility applications, the nvblox library enables real-time 3D occupancy grid generation, allowing robots to identify obstacles up to five meters away at speeds 100x faster than with CPU-centric methods. NVIDIA cuVSLAM provides sub-1% trajectory errors for real-time, CUDA-accelerated visual SLAM across diverse sensors and platforms. NVIDIA COMPASS trains vision-based mobility foundation models for navigation across different robot types and environments.

NVIDIA Isaac Sim, built on NVIDIA Omniverse, provides a physically based virtual environment for developing autonomous machines. Isaac Lab is a lightweight application optimized for robot learning and foundation model training. Newton is an open-source, GPU-accelerated physics engine optimized for robotics.

NVIDIA Isaac GR00T is an open reference platform for general-purpose humanoid robot development, comprising open data, foundation models, simulation frameworks, middleware, and runtime libraries for inference and control.
