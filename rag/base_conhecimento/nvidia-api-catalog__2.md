NVIDIA NIM provides containers to self-host GPU-accelerated inferencing microservices for pretrained and customized AI models across clouds, data centers, and RTX AI PCs and workstations. The microservices expose industry-standard APIs designed for straightforward integration into AI applications, development frameworks, and workflows, while optimizing response latency and throughput for each specific combination of foundation model and GPU hardware. The platform streamlines the transition from experimentation to deploying enterprise-grade AI applications, serving enthusiasts, developers, and AI builders with pre-optimized models and standard APIs for building AI agents, co-pilots, chatbots, and assistants. Inference engines come from leading frameworks from NVIDIA and the community, including TensorRT, TensorRT-LLM, vLLM, SGLang, and more.

Performance: accelerated engines from NVIDIA and the community arrive prebuilt and optimized specifically for low-latency, high-throughput inferencing on particular NVIDIA GPU systems, so developers get better application performance and efficiency without tuning the serving stack themselves.

Deployment flexibility and control: prebuilt microservices can be deployed on NVIDIA GPUs anywhere, keeping applications and data secure and under the organization's control. Developers can download NIM inference microservices for self-hosted deployment or use dedicated endpoints on Hugging Face to launch instances within their preferred cloud environment.

Model selection and customization: NIM supports deployment across a broad spectrum of large language models compatible with vLLM, SGLang, or TensorRT-LLM, including community fine-tuned models and models fine-tuned on an organization's own data.

Operationalization: detailed observability metrics are available for dashboarding, and Helm charts plus scaling guides are provided for running NIM on Kubernetes.

Try phase, the NVIDIA API Catalog: developers receive free access to NIM API endpoints supporting unlimited prototyping, powered by DGX Cloud. Membership in the NVIDIA Developer Program unlocks NVIDIA-hosted NIM APIs and containers for development and testing. The NVIDIA API Catalog is the central hub where developers explore and experiment with available models directly through a browser interface. Members generate API keys for programmatic access and use OpenAI-compatible API patterns, so integration with existing development workflows and applications is straightforward.

Build phase, blueprints and sample applications: developers jumpstart projects using sample applications built with NIM alongside partner microservices. NVIDIA Blueprints are predefined, customizable AI workflows for creating and deploying AI agents and generative AI applications. Blueprints can be deployed with one click through NVIDIA Launchables, downloaded for local deployment on PCs and workstations, or used for development within a data center or private cloud. They are co-developed with leading agentic AI platform providers including CrewAI and LangChain. The NVIDIA AgentIQ toolkit, a developer library for building AI agents, enables integration of NIM microservices into custom agentic workflows.

Deploy phase, from prototype to production: developers deploy on their own infrastructure for development and testing. When an organization is ready for production, it gains security assurance, API stability, and professional support through NVIDIA AI Enterprise. Alternatively, developers can access dedicated enterprise-grade NIM endpoints available through NVIDIA partners.

Applications: developers can build accelerated generative AI applications incorporating retrieval-augmented generation pipelines, agentic AI workflows, and related capabilities. NVIDIA provides generative AI examples through GitHub repositories demonstrating deployment of complex AI systems powered by NIM through NVIDIA-hosted API endpoints.
