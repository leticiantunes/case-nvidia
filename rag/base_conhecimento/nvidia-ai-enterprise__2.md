NVIDIA AI Enterprise is a complete software platform for developing, deploying, and managing AI applications across cloud, data center, and edge environments. The platform is organized into two distinct but complementary layers. The Application Layer delivers AI frameworks, NIM microservices, and SDKs. The Infrastructure Layer provides GPU drivers, Kubernetes operators, and cluster management tools. Each layer has independent release branches and lifecycles, plus enterprise support backed by SLAs. Because the stack is composable, teams do not have to adopt the entire platform at once: they can select application development components such as NIM microservices, NeMo, Omniverse, and AI frameworks and pair them with infrastructure management components such as Run:ai, Kubernetes operators, Base Command Manager, and drivers according to their requirements.

Application Layer contents and branches: the Application Layer includes production-ready AI frameworks, NVIDIA NIM microservices for model deployment, domain-specific SDKs, NVIDIA Omniverse, and pre-trained models, all included in the NVIDIA AI Enterprise license. Release branches follow two patterns. Production Branches deliver production-ready AI frameworks with 9-month support, giving teams stable validated software with predictable upgrade windows. Long-Term Support Branches provide 36 months of API stability for highly regulated industries where framework changes would impose substantial refactoring burdens. Active branches include Production Branch 6, compatible with Infrastructure Releases 7 and 8, and Long-Term Support Branch 2, compatible with Infrastructure Releases 4 and 7. NVIDIA Omniverse maintains its own separate production branches.

Infrastructure Layer contents and branches: this layer handles the systems-level requirements underpinning AI workloads and includes GPU drivers, Kubernetes operators for GPU orchestration, the NVIDIA Network Operator for cluster networking, the NVIDIA Container Toolkit for containerized environments, NVIDIA Run:ai for workload scheduling in both self-hosted and SaaS models, and cluster management tools. It runs on a distinct release cadence from the Application Layer. Infrastructure branches generally provide regular updates with 1-year support windows, while Long-Term Support designated branches receive extended 3-year support. Active infrastructure releases include Infra 8 as the current Production Branch and Infra 7 as the current Long-Term Support Branch.

Lifecycle policy and compatibility tooling: the Lifecycle Policy documentation defines the release branch strategy, support timelines, and end-of-life schedule for every NVIDIA AI Enterprise component, and guides teams in choosing between Feature Branch, Production Branch, and Long-Term Support Branch releases. An Interactive Lifecycle and Compatibility Explorer validates cross-stack compatibility between GPU drivers, NVIDIA GPU Operator, NVIDIA Network Operator, and NVIDIA Run:ai versions before deploying or upgrading. An Interactive Support Matrix allows checking supported configurations across infrastructure releases with filters by deployment type, operating system, hypervisor, orchestration platform, GPU architecture, Kubernetes distribution, or cloud provider.

Support model: all NVIDIA AI Enterprise subscriptions include enterprise support. The Business Standard tier grants access to NVIDIA AI experts during local business hours with SLA-backed response times. The Business Critical tier adds 24/7 coverage with accelerated response times for production issues. A Technical Account Manager service provides a dedicated NVIDIA expert for strategic guidance and deployment planning. The Licensing Guide covers licensing models, entitlement activation, license server configuration, and subscription management for all deployment types.
